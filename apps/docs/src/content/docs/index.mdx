## What is Inti.js?

:::caution[For Astro sites]
Inti is not a plugin you install inside WordPress or any other CMS, and it does not change its admin panel. It renders your site with Astro and saves edits to the CMS you already have. If your site is still drawn by a WordPress theme, the first step is moving the frontend to Astro, and Inti is the way to do it without migrating the content.
:::

:::note[Beta]
Inti is at 0.1: it works and you can try it, and its API may still change before 1.0.
:::

A layer **on top of** the CMS you already have. The content keeps living in WordPress; Inti renders it as Astro components and lets the editor change it by double-clicking on the page itself. The change is written back to the CMS through its API.

Inti is not a CMS and does not try to be one: it has no admin panel, no users and no database of its own.

## How it works

1. An **adapter** reads the page from the CMS and turns it into a list of typed blocks.
2. `BlockRenderer` draws each block with the Astro component you wrote for that type.
3. In edit mode, the editor double-clicks, changes the text and saves.
4. An Astro **action** receives the change on the server and the adapter writes it to the CMS. Credentials never leave the server.

## Installation

```bash
npm install @intijs/core @intijs/adapter-wordpress
npx astro add node
```

The rest —registering the integration, exposing the action and creating the block components— is in the [First Project](/guides/quickstart/). No step is optional.
